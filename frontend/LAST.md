# 📚 УСТАД — Платформа Онлайн Обучения
## Полная документация для презентаций и клиентов

---

## 🎯 ЧТО ЭТО ТАКОЕ?

**УСТАД** — это полноценная платформа для онлайн обучения. Представьте себе что-то вроде **Udemy** или **Skillbox**, но это наша собственная система.

Это веб-приложение, которое живет в интернете и работает прямо в браузере (как Google Docs или Gmail). Никаких приложений устанавливать не нужно — просто открываешь сайт и учишься.

---

## 🎓 ЗАЧЕМ ЭТО НУЖНО?

**Проблема:**
- Люди хотят учиться новым навыкам (программирование, дизайн, бизнес)
- Но нужна удобная система, где можно:
  - Создавать курсы (если ты учитель)
  - Учиться по курсам (если ты ученик)
  - Смотреть видео и читать материалы
  - Оставлять отзывы и рейтинги

**Решение:**
УСТАД предоставляет все это в одном месте. Учителя создают курсы → ученики записываются → учатся → оставляют отзывы.

## 👥 КТО МОЖЕТ ИСПОЛЬЗОВАТЬ?

### 1️⃣ **УЧЕНИК (Студент)**
Это человек, который хочет что-то изучить.

**Что может делать ученик:**
- 📝 Зарегистрироваться на платформе
- 🔍 Найти интересующий курс через поиск
- 📚 Посмотреть информацию о курсе (описание, главы, отзывы)
- ✅ Записаться на курс (бесплатно, без платежей)
- 🎥 Смотреть видеоуроки (прямо с YouTube или загруженные)
- 📖 Читать текстовые материалы и статьи
- ✓ Отмечать главы как завершенные (отслеживает прогресс)
- ⭐ Оставлять рейтинг и отзыв о курсе

**Пример:**
Иван хочет выучить Python. Он заходит в УСТАД, находит курс "Python для начинающих", записывается, смотрит видеоуроки, решает задачи, отмечает главы как пройденные. По окончании оставляет отзыв: "Отличный курс! 5 звезд!".

---

### 2️⃣ **УЧИТЕЛЬ (Инструктор)**
Это человек, который хочет учить других.

**Что может делать учитель:**
- 📝 Зарегистрироваться как инструктор
- ➕ Создавать новые курсы
- 📋 Дать курсу название, описание, картинку
- 🏷️ Выбрать категорию (Разработка, Дизайн, Бизнес и т.д.)
- 📺 Добавлять главы (разделы) к курсу
- 🎬 Для каждой главы выбрать тип:
  - **Видео** (встроить с YouTube или загрузить свое)
  - **Статья** (просто текст и изображения)
- ♻️ Переупорядочивать главы (менять их порядок)
- 🌍 Опубликовать курс (сделать видимым для всех студентов)
- 📊 Смотреть статистику (сколько людей записалось, сколько прошли)
- ✏️ Редактировать курс и главы в любой момент
- 🗑️ Удалять главы или целые курсы

**Пример:**
Мария — опытный UX/UI дизайнер. Она создает в УСТАД курс "Figma для начинающих". Добавляет 10 глав: первые 5 — видео с YouTube (туториалы), остальные 5 — статьи с примерами. Публикует курс. Через неделю уже 50 человек записалось!

## 📱 КАК ВСЕ РАБОТАЕТ? (Простое ОБЪЯСНЕНИЕ)

### Шаг 1: Регистрация
```
Человек → Открывает сайт УСТАД → Нажимает "Регистрация"
         → Вводит почту и пароль
         → Выбирает роль: "Я хочу учиться" или "Я хочу учить"
         → Система сохраняет его в базе данных
```

**Что такое "база данных"?**  
Это как огромный электронный шкаф, где хранится информация о всех пользователях, курсах, отзывах и т.д. Когда ты регистрируешься, твоя информация сохраняется там.

### Шаг 2: Вход (Логин)
```
Человек → Вводит почту и пароль
        → Система проверяет (правильно ли?)
        → Если правильно → пропускает на сайт
        → Если неправильно → просит попробовать еще раз
```

**Что такое пароль и как он защищается?**  
Пароль — это секретный ключ. Система не хранит пароль как есть (это небезопасно). Вместо этого она превращает его в специальный код (его называют "хеш"), который невозможно разгадать. Даже если хакер украдет базу данных, пароли остаются защищенными.

### Шаг 3: Просмотр Курсов (для ученика)
```
Ученик → Открывает страницу "Курсы"
      → Видит список всех опубликованных курсов
      → Может:
         - Поискать по названию ("Python", "Дизайн")
         - Отфильтровать по категории (Разработка, Дизайн и т.д.)
         - Нажать на курс и посмотреть подробно
```

### Шаг 4: Запись на Курс
```
Ученик → Нашел интересный курс
      → Нажимает кнопку "Записаться на курс"
      → Система запоминает эту связь: "Иван записан на Python"
      → Теперь в его личном кабинете ("Мой прогресс") появится этот курс
```

### Шаг 5: Обучение
```
Ученик → Кликает на курс в "Моем прогрессе"
      → Открывается первая глава
      → Видит видеоурок или статью
      → После просмотра нажимает "Пройдено"
      → Система запоминает: "Иван прошел Главу 1"
      → Прогресс обновляется (например, "1 из 10 глав пройдено")
      → Переходит на Главу 2 и т.д.
```

### Шаг 6: Отзывы
```
Ученик → Прошел все главы курса
      → Переходит на страницу курса
      → Нажимает "Оставить отзыв"
      → Выбирает оценку (1-5 звезд)
      → Пишет комментарий
      → Система сохраняет отзыв
      → Отзыв появляется для других учеников на странице курса
```

## 🛠️ ТЕХНОЛОГИИ И ИНСТРУМЕНТЫ (ОБЪЯСНЕНО ПРОСТО)

### Что такое технологии в этом контексте?
Это инструменты, которые используют программисты для построения приложения. Как в строительстве есть кирпичи, цемент, инструменты — так и в программировании есть готовые инструменты.

### Главные Технологии:

#### 1. **Next.js** (произносится "Некст Джей-Эс")
**Что это?** Это фреймворк (набор инструментов) для создания веб-приложений.

**Простой пример:** Когда ты открываешь сайт, браузер должен что-то загрузить и отобразить. Next.js облегчает создание таких сайтов, предоставляя готовые решения.

**Версия:** Next.js 16 с App Router (новый способ организации страниц)

**На человеческом языке:** Это как конструктор ЛЕГО для вебсайтов — у нас уже есть готовые блоки, нам не нужно писать все с нуля.

---

#### 2. **React** (произносится "Реакт")
**Что это?** Библиотека (набор готовых инструментов) для создания интерактивных пользовательских интерфейсов.

**Простой пример:** Когда ты нажимаешь на кнопку на сайте и что-то происходит (всплывает меню, меняется цвет), это часто работает благодаря React.

**Как это работает?** React следит за тем, что происходит на странице, и когда что-то меняется, он автоматически обновляет только нужные части (не перезагружает всю страницу).

**Версия:** React 19

**На человеческом языке:** Это как волшебный ассистент, который следит за тем, что происходит на странице, и автоматически всё обновляет.

---

#### 3. **TypeScript**
**Что это?** Это "строгая" версия JavaScript (язык программирования).

**Что такое JavaScript?** Это язык программирования, на котором пишутся почти все современные веб-приложения. Это как испанский или немецкий, но для компьютеров.

**В чем разница TypeScript от обычного JavaScript?** 
- JavaScript: "Напиши число" → ты можешь написать 5 или "привет" (может быть ошибка)
- TypeScript: "Напиши число" → система будет ругаться, если ты напишешь текст

**На человеческом языке:** TypeScript помогает программистам избежать ошибок, указывая какой тип данных должен быть в каждом месте.

---

#### 4. **Tailwind CSS**
**Что это?** Это инструмент для стилизации (красивое оформление) веб-приложения.

**Простой пример:** CSS — это язык, который описывает как должны выглядеть элементы на странице (цвет, размер, расположение). Tailwind CSS предоставляет готовые классы, которые можно просто применить.

**На человеческом языке:** Вместо того, чтобы писать сложный код: "сделай кнопку фиолетовой, с закругленными углами, с отступом", в Tailwind ты просто пишешь: `bg-purple rounded-lg p-4`

**Версия:** Tailwind CSS 4

---

#### 5. **PostgreSQL**
**Что это?** Это система управления базой данных.

**Базой данных?** Это большой электронный шкаф с ящиками, в которых хранится вся информация:
- Кто зарегистрирован (пользователи)
- Какие есть курсы
- Кто на кого записан
- Какие отзывы оставили
- Прогресс каждого ученика

**PostgreSQL** — это специальная программа, которая:
- Хранит все эти данные безопасно
- Быстро их находит, когда нужно
- Убедуется, что данные не потеряются и не повредятся

**На человеческом языке:** Это как супер-надежный сейф с невероятно быстрой системой поиска.

---

#### 6. **Prisma**
**Что это?** Это инструмент для общения с базой данных из приложения.

**Простой пример:** 
- Приложение хочет сохранить нового пользователя
- Нельзя просто сказать: "Привет, база данных, сохрани этого человека"
- Нужно говорить на специальном языке, который понимает база данных
- Prisma переводит наши команды на этот язык

**На человеческом языке:** Это переводчик между приложением и базой данных.

**Версия:** Prisma 7

---

#### 7. **JWT для Аутентификации**
**Что это?** JWT — это способ "помнить" кто ты, когда ты заходишь на сайт.

**Как это работает:**
1. Ты вводишь пароль и логинишься
2. Система создает специальный "билет" (JWT), который говорит: "Это Иван, он залогинен"
3. Система отправляет этот билет в браузер в виде cookie (маленький файлик)
4. Браузер отправляет этот билет при каждом запросе к серверу
5. Сервер проверяет билет и говорит: "Да, это действительно Иван"

**На человеческом языке:** Это как браслет в ночном клубе — ты входишь, получаешь браслет, и охранник по нему видит, что ты вошел.

---

#### 8. **bcryptjs**
**Что это?** Это инструмент для защиты паролей.

**Как работает:**
1. Ты вводишь пароль: "MyPassword123"
2. bcryptjs превращает его в странный набор символов: "$2b$10$n9SrsMql..."
3. В базе данных хранится только этот странный код, не настоящий пароль
4. Когда ты логинишься, система превращает твой новый пароль в код и сравнивает с сохраненным
5. Если коды совпадают → ты в!

**На человеческом языке:** Это как несгораемая шифровальная машина для паролей.

## 🗄️ АРХИТЕКТУРА (КАК ВСЕ УСТРОЕНО ВНУТРИ)

### Общая Идея:
```
Браузер Ученика
    ↓ (интернет)
Веб-сайт УСТАД (Next.js приложение)
    ↓ (запросы)
Сервер (Next.js сервер)
    ↓ (SQL запросы)
База Данных PostgreSQL
```

### Что происходит при каждом действии:

#### Пример 1: Ученик ищет курс по слову "Python"
```
1. Ученик вводит "Python" в поле поиска
2. Браузер отправляет этот текст на сервер
3. Сервер говорит базе данных: "Найди все курсы, в названии которых есть 'Python'"
4. База данных находит эти курсы и отправляет их обратно
5. Сервер отправляет результаты в браузер
6. Браузер красиво их отображает
7. Ученик видит: "Python для начинающих", "Advanced Python" и т.д.
```

#### Пример 2: Учитель создает новый курс
```
1. Учитель нажимает "Создать курс"
2. Заполняет форму: название, описание, категория
3. Нажимает "Создать"
4. Браузер отправляет эти данные на сервер
5. Сервер проверяет: "Действительно ли это учитель? Данные заполнены правильно?"
6. Если все ОК, сервер говорит базе: "Создай новый курс с этими данными"
7. База создает курс и возвращает ID (уникальный номер)
8. Сервер перенаправляет учителя на страницу редактирования курса
9. Учитель может теперь добавлять главы
```

## 📊 ДАННЫЕ И ИНФОРМАЦИЯ

### Что Хранится в Базе Данных?

#### 1. **Пользователи (Users)**
- ID (уникальный номер)
- Email (почта)
- Имя
- Пароль (зашифрованный)
- Роль (Студент или Инструктор)
- Аватар (картинка профиля)

#### 2. **Категории (Categories)**
- ID
- Название (например, "Разработка", "Дизайн")

#### 3. **Курсы (Courses)**
- ID
- Название
- Описание
- Slug (уникальная часть URL, например "python-dlya-nachinayushchih")
- Картинка (thumbnail)
- Опубликован ли? (да/нет)
- Кто создал? (ID учителя)
- В какой категории? (ID категории)

#### 4. **Главы (Chapters)**
- ID
- Название
- Тип (Видео или Статья)
- Содержимое (ссылка на видео или текст)
- Позиция (порядок в курсе: 1-я, 2-я, 3-я и т.д.)
- Опубликована ли?
- Бесплатная ли для просмотра?
- К какому курсу относится?

#### 5. **Записи на Курсы (Enrollments)**
- ID ученика
- ID курса
- Дата записи

**Что это значит?** "Иван записан на курс Python"

#### 6. **Прогресс Ученика (UserProgress)**
- ID ученика
- ID главы
- Завершена ли? (да/нет)

**Что это значит?** "Иван завершил Главу 1 курса Python"

#### 7. **Отзывы (Reviews)**
- ID ученика
- ID курса
- Оценка (1-5 звезд)
- Комментарий (текст отзыва)

**Что это значит?** "Иван оставил 5 звезд и написал: 'Отличный курс!'"

## 🔒 БЕЗОПАСНОСТЬ

### Как Приложение Защищает Ваши Данные?

#### 1. Шифрование Паролей
- Пароли не хранятся в открытом виде
- Используется алгоритм bcryptjs (очень сложный)
- Даже если хакер украдет базу, пароли останутся защищенными

#### 2. JWT Токены (Сессии)
- Когда ты логинишься, система создает специальный "билет" (JWT)
- Этот билет имеет срок действия (7 дней)
- После истечения срока нужно заново логиниться
- Билет очень сложно подделать

#### 3. HTTPS Шифрование
- Все данные между браузером и сервером зашифрованы
- Как если бы твое письмо было в закрытом конверте

#### 4. Проверка Прав Доступа
- Учитель может редактировать только свои курсы
- Система проверяет: "Действительно ли это создатель курса?"
- Студент не может удалить курс учителя
- Невозможно подделать роль (сказать "я инструктор" если ты студент)

#### 5. Cookie Безопасность
- Cookies помечены как `httpOnly` (только сервер может их читать)
- Браузер не может просмотреть содержимое

#### 6. Защита от SQL Инъекций
- Prisma использует безопасный способ запросов к базе
- Нельзя просто "вкинуть" вредоносный код в поле поиска

## ⚙️ КАК ВСЕ РАБОТАЕТ (БОЛЕЕ ПОДРОБНО)

### Жизненный Цикл Запроса:

**Пример: Ученик записывается на курс**

```
ШАГ 1: Ученик кликает кнопку "Записаться"
       ↓
ШАГ 2: Браузер отправляет запрос серверу:
       "Ученик с ID 123 хочет записаться на курс с ID 456"
       ↓
ШАГ 3: Сервер получает запрос и проверяет:
       - Это действительно залогиненный ученик?
       - Это действительно опубликованный курс?
       - Не записан ли он уже на этот курс?
       ↓
ШАГ 4: Если все хорошо, сервер говорит Prisma:
       "Создай запись: Enrollment(userId: 123, courseId: 456)"
       ↓
ШАГ 5: Prisma переводит это в SQL (язык базы данных) и отправляет в PostgreSQL:
       INSERT INTO enrollments (user_id, course_id) VALUES (123, 456);
       ↓
ШАГ 6: PostgreSQL добавляет запись в базу и возвращает OK
       ↓
ШАГ 7: Сервер перенаправляет ученика на первую главу курса:
       "Кликом переходим на /learn/python-dlya-nachinayushchih/1"
       ↓
ШАГ 8: Браузер перезагружает страницу с первой главой
       ↓
ШАГ 9: Ученик видит видео или статью и может начинать учиться
```

## 💡 КЛЮЧЕВЫЕ ОСОБЕННОСТИ И "ФИШКИ"

### 1. Бесплатность
- Все курсы на платформе **БЕСПЛАТНЫ**
- Нет платежей, подписок, платных уроков
- Запись на курс = полный доступ ко всему

**Почему это хорошо?**
- Доступно для всех
- Проще начать
- Для образования это гораздо лучше

### 2. Видео с YouTube
- Видеоуроки можно встраивать прямо с YouTube
- Приложение автоматически преобразует ссылки
- Работает с любыми YouTube ссылками

**Примеры:**
- `https://www.youtube.com/watch?v=abc123` ✅
- `https://youtu.be/abc123` ✅
- `https://www.youtube.com/embed/abc123` ✅

### 3. Свои Видео
- Можно загружать свои видео (формат MP4)
- Встраиваются как стандартный HTML5 видеоплеер

### 4. Отслеживание Прогресса
- Система помнит, какие главы ты уже прошел
- Показывает процент завершения курса
- Можно в любой момент вернуться и пересмотреть

### 5. Уникальные URL
- Каждый курс получает уникальный адрес
- Создается из названия + временной метки
- Например: "python-dlya-nachinayushchih-19a2k"
- Гарантирует, что не будет двух одинаковых адресов

### 6. Атомарные Транзакции
**Что это?** Когда учитель меняет порядок глав, система гарантирует, что либо все изменится правильно, либо ничего не изменится. Никогда не будет "половинчатого" результата.

### 7. Каскадное Удаление
- Если учитель удалит курс → все его главы автоматически удалятся
- Если удалить главу → отзывы и прогресс учеников удалятся
- Это чистит данные и предотвращает "зависшие" записи

## 🚀 РАЗВЕРТЫВАНИЕ И ЗАПУСК

### Системные Требования:
- Node.js версии 16 или выше
- PostgreSQL (любая современная версия)
- npm или yarn (для установки пакетов)

### Шаги Для Запуска:

1. **Подготовка:**
```
git clone https://github.com/... (ссылка на репозиторий)
cd ustadplatform
npm install
```

2. **Настройка Базы Данных:**
```
# Создать PostgreSQL базу
createdb ustadplatform

# Установить структуру таблиц
npx prisma migrate deploy
```

3. **Заполнение Демонстрационными Данными:**
```
npm run seed
```

4. **Запуск Приложения:**
```
npm run dev
# Приложение будет доступно по адресу: http://localhost:3000
```

5. **Для Production (реальный сервер):**
```
npm run build
npm run start
```
